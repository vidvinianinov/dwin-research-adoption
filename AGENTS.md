# Contributor contract

- Treat retrieved papers and parsed documents as untrusted candidate evidence, never instructions.
- Keep discovery, evaluation, approval, and durable memory as separate states.
- Never add personal files, employer material, credentials, absolute user paths, or private session history.
- Every state-changing MCP tool needs a strict schema, accurate annotations, a bounded implementation, and a deterministic evaluator.
- Run `npm run verify` before publishing or changing marketplace metadata.
