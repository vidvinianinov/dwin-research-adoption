# Durable memory policy

A durable claim needs a current adoption record, an accepted experiment, exact provenance, declared scope, confidence, expiry, and explicit human approval. Retrieval exposes only approved, non-expired, non-superseded claims by default.

Candidates are not active memory. Hashes are identities, not evidence. Receipt presence does not establish causal improvement beyond the evaluator's declared scope. Reopen cited evidence before material reuse, and preserve limitations with the claim.

Memory is append-only. Correct by supersession; validate expiry and source availability; never silently mutate an earlier claim.
